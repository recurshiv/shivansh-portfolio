01 · Lead project · Full stack

SyncDocs

A rich-text document editor on the MERN stack, built so your writing is never lost.

  • “Saved” appears only once the server confirms; failed saves can be retried.
  • Revision checks stop a stale tab from overwriting newer text.
  • Private documents, server-side sessions, 24 end-to-end browser checks.

✦ Click the scene to type a line and watch it autosave.

02 · Hackathon team project

Universal Clipboard Sync

An Electron app, built with my hackathon team, that syncs copied text and images between paired computers over WebRTC.

My follow-up in the fork

  • Pairing bound to the device, with one-time codes.
  • Bounded transfers: 32 KiB text, 10 MiB images.
  • Clean disconnects; 57 automated tests.
